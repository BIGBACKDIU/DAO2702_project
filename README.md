# DAO2702 Project: Singapore Homebuyer Story

Datasets and reproducible Google Colab notebook for the Singapore 2025 private-property homebuyer analysis.

## Run in Colab

Open `Singapore_Homebuyer_Story_2025_v4_Colab.ipynb` in Google Colab and run the added first setup cell to download the six datasets from this repository before running the original analysis.

## Data

- `properties2025.csv`
- `properties_2020_2025_clean.csv`
- `sg_map.json`
- `sg_mrt.json`
- `project_coords.csv`
- `mrt_station_openings.csv`

The analytical code and source datasets retain their original content; only a separate Colab setup cell was added.
